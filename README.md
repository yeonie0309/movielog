# MovieLog

UMC 11기 PE(Mobile) 0주차 Flutter 필수 미션 프로젝트입니다.

## 실행

```bash
flutter pub get
flutter run -d emulator-5554
```

## Dart 연습 실행

```bash
dart run lib/week0/dart_practice.dart
```

`Movie` 클래스, `List<Movie>`, 반복문, Null Safety 기본값 처리를 확인할 수 있습니다.
