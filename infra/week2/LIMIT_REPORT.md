# 한계 측정 리포트
상태: Grafana 계정 준비 및 실제 AWS 재구성 전. 측정값 없음.
워크북 참고 숫자는 본인 실측값으로 사용하지 않는다.

처리량이 꺾이는 지점: 미측정. 로컬 통과 결과나 SLO 목표값을 클라우드 성능으로 대체하지 않는다.
부하 구간40초, timeout5초, baseline8초, 매단계 새회원/JWT, 사전probe는counter범위 밖.
실패는 timeout / network / client4xx / server5xx / dropped로 분리한다.
단계별 실행시각과 Grafana 쿼리 창을 남긴다. SSM tunnel·로컬 측정기 자체가 병목인지도 확인한다.
5xx가 늘었다는 이유만으로 시나리오 오류라고 단정하지 않는다. DB/CPU/지연/로그 등 실제 원인을 확인한다.
