# 4주차 프론트엔드 실행 증빙

- `loading.png`: Skeleton Loading 화면
- `success.png`: 영화 목록 Success 화면
- `empty.png`: 영화 목록 Empty 화면
- `flutter_analyze.txt`: `flutter analyze --no-fatal-infos` 실행 결과
- `error_retry_success.mp4`: Error → Retry → Loading → Success 실행 영상
- `genre_persistence_restore.mp4`: 장르 선택값 저장 후 앱 화면 재생성·복원 영상

두 영상은 Android 에뮬레이터에서 통합 테스트로 실제 위젯을 조작해 녹화했습니다.
